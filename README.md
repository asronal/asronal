### `01` — RV64-AI-MCU

**[Open repository →](https://github.com/asronal/RV64-AI-MCU)**

Custom RV64 AI-oriented MCU/SoC written in Verilog, covering processor architecture, memory, DSP, AI acceleration, peripherals and ASIC synthesis flow.

`RV64IMC` `5-stage pipeline` `DSP` `SIMD` `MAC` `INT8 TPU` `Synopsys DC`

### `02` — SkyNetics Rescue Drone

**[Open repository →](https://github.com/asronal/SkyNetics-RAS-drone)**

Embedded search-and-rescue platform using Raspberry Pi 4, RGB vision, MLX90640 thermal sensing, LD2450 mmWave radar and onboard sensor fusion.

`Raspberry Pi` `Embedded Linux` `Thermal` `mmWave` `Computer Vision` `Sensor Fusion`

### `03` — Road Obstacle & Pothole Detection

**[Open repository →](https://github.com/asronal/Obstacle-and-Pothole-detection-model)**

Real-time YOLOv8/ONNX inference pipeline deployed on Raspberry Pi 4, reaching approximately **5–7 FPS** with CPU inference.

`YOLOv8` `ONNX` `OpenCV` `Raspberry Pi` `Edge AI`
